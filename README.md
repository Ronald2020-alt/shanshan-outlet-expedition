# 杉杉奥莱 · 奥莱远征，品质长征

杉杉奥莱企业文化互动游戏。完整远征 29 关、新星启程 19 关、文化漫游 12 关。

包含自适应原创背景音乐、交互音效、支持设备上的触感反馈、文化手册、自动存档和通关海报。

## 运行

通过 GitHub Pages 打开即可游玩；也可以下载 index.html 后用现代浏览器直接打开。

开始游戏后播放音乐，使用右上角“体验设置”可分别调整背景音乐、音效、震动和动态效果。切换到后台时音乐暂停。震动需要浏览器与硬件支持，iPhone Safari 等不支持时保留视觉与声音反馈。

学习记录只保存在当前浏览器，不发送到服务器。排行榜为本机档案记录，并非联网企业全员排名；换设备前可导出存档。

## 发布结构

index.html 是自包含发布文件，内置脚本、样式与压缩图片，无外部运行依赖。版本 2.1.0。

内容与素材用于杉杉奥莱文化体验，未附加开源素材授权。
